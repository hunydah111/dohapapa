# 부동산 촉 게임 — 스펙 (peer 아웃퍼폼 예측)

> 상태: **스펙 (미구현)**. 2026-05-31 브레인스토밍 결론. 다음=플랜→TDD.
> 한 줄: **돈이 아니라 *시세 보는 눈(촉)*으로 줄 세우는 데일리 예측 게임.** 게임이 매일
> 트래픽을 끌고, 비집고 본체(내 통장 집찾기)가 전환·깊이를 먹는다.

## Context (왜)
비집고는 저빈도 *의사결정 도구*라 매일 열 이유가 없었다. 브레인스토밍에서 검증·폐기한 것:
인스타 등급-flex(짜침·돈자랑 처벌), 자산배분 전면피벗(사업성·재미 없음), 수동 워치/다이제스트
(미지근). 살아남은 통찰: **줄세우기를 부(富)→실력(촉)으로, 정보를 수동→예측 게임으로 옮기면
짜침 없이 매일·재밌고·가볍다.** 벤치마크는 "전체 평균"(뻔함)이 아니라 **peer(같은 가격대)**여야
불확실성=실력=재미가 산다.

## Concept / 포지셔닝
- 비집고 안의 **데일리 게임 탭**(본체 유지, 전면 피벗 아님).
- "이 동네(가격대), **같은 가격대 평균(시장) 이길까?**" UP(아웃퍼폼)/DOWN 베팅 → 채점 → **촉 점수·연승·"부동산 촉 N단"**.
- 비지 캐릭터 재배치: 지위 뱃지 → *게임 마스코트·촉 등급*.

## 코어 루프 (2모드 — 복기가 느린 채점 문제를 푼다)
1. **복기 모드 (instant, MVP 1순위)**: 과거 한 시점을 가리고 "그때 이 셀이 평균 이겼을까?" → **즉시 채점**(13개월 trendIndex 히스토리). 대기 0 = 즉각 도파민, 촉 기록 빠르게 쌓음. 온보딩·일일 플레이의 핵심.
2. **라이브 예측**: "향후 1개월 이 셀, peer 이길까?" → 월간 trendIndex 갱신 시 resolve. 진짜 베팅.
→ 매일 열 이유 = 새 복기 라운드(무한) + 라이브 결과 발표(롤링) + 연승/랭킹 넛지.

## 예측 대상 & 벤치마크 (실데이터로 정의)
- **대상 = (시군구 × 가격대) 셀** — `trendIndex.series["{시군구}|{tier}"]`. tier = `tierOf(price)` (low<10억·mid 10~30억·high 30억+). 사용자는 관심 단지/동네로 진입 → 그 셀로 매핑.
- **peer 벤치마크 = `trendIndex.series["수도권|{tier}"]`** (같은 가격대 수도권 평균).
- **채점**: horizon(1개월/분기) 동안 `Δ대상셀index` vs `Δpeer index`. 대상이 더 오르면 UP 적중.
- **플레이 가능 집합**: 자기 series가 있는 셀만(데이터 부족 시 build가 수도권|tier로 폴백 → 대상==벤치마크면 게임 불가). 유동성 있는 시군구×tier만 출제. (정직한 한계)

## 점수 / 랭킹 (실력, 부 아님)
- 적중 +점, 연승 보너스. 누적 정확도 → **"부동산 촉 N단"**.
- **핵심: 랭킹 축 = 촉 정확도. 구매력·돈 절대 아님.** → 저예산 유저도 촉 9단 가능. 신분(돈)과 지위(촉)를 *완전 분리* = 짜침·박탈감 구조적 제거.

## 통장 연결 (비집고만의 모트)
- 베팅 화면에 "네 예산이면 이 셀 진입 가능? △억 부족/이미 가능". 적중과 별개로 *내 일*로 엮음.
- "맞췄는데 내 예산 밖이네 ㅋㅋ" 같은 자조 = 한국에서 flex보다 잘 퍼지는 톤.

## 가드 (성패 가름)
- **박탈감**: 사람 줄세우기 금지(촉 랭킹은 실력이라 OK, 돈 랭킹 금지). 못 맞춰도 "촉 더 키우자"(선망), "꼴등"(시기) 금지. [[feedback_price_first_scoring]] 박탈감 룰 연장.
- **컴플라이언스**: 실제 돈 0(촉 점수만) = 도박 아님. 예측은 지수 *방향* 게임이지 "사라/팔라" 자문 아님. "시세 감각 게임 · 투자권유·예측 아님" 면책. 투기 톤 금지.
- **콜드스타트**: 복기 모드로 *혼자서도* 즉시 재밌음(멀티 의존 X). 친구는 카톡 도발("야 너 이거 UP이냐 DOWN이냐")로 증폭.

## 데이터 & 가벼움 (+ 정직한 한계)
- 전부 번들 `trendIndex.json`(시군구×가격대×월) + 순수계산. **런타임 DB 0, Neon 무관.**
- **한계 1 (히스토리)**: trendIndex ~13개월뿐 → 복기 라운드 풀이 제한적. A4(윈도우 확대)·A5(R-ONE) 하면 풀↑.
- **한계 2 (라이브 채점 지연)**: 월간 갱신이라 라이브 예측은 수주 후 resolve. → 복기(instant) + 다수 라이브 동시진행 + 결과 롤링으로 *체감 daily* 만듦. **이게 #1 검증 리스크.**
- **한계 3 (3극화 거침)**: tier 3단(low/mid/high)이라 peer가 거침. 가격대 세분(예 5단)은 trendIndex 재설계 필요 — 후속.

## MVP 슬라이스 (가장 작게)
**복기 모드 단독** — `/play`(가칭) 탭: 랜덤 (시군구×tier) 셀 + 가려진 과거 시점 → UP/DOWN → 즉시 채점 → 촉 점수·연승(localStorage). 통장 연결 1줄 + 카톡 공유 도발. **라이브 예측·랭킹·구독은 2차.**
- 왜 복기부터: 대기 0이라 *재미 가설을 즉시 검증*(사람들이 이 예측을 재밌어하나?). 재미 없으면 라이브 만들 필요도 없음.

## 남은 결정 (플랜 단계)
- horizon(라이브): 1개월 vs 1분기.
- 출제 큐레이션: 완전 랜덤 vs 인기/관심 셀 가중.
- 점수식 상세(연승 보너스·난이도 가중 — 박빙 셀 맞히면 +α?).
- 탭 진입점/네비 위치.

## 검증 (TDD + 실사용)
- 순수 채점 함수 `scoreRound(cell, benchmark, fromMonth, toMonth)` TDD: 아웃퍼폼/언더/동률·데이터없음 케이스.
- 복기 출제 가능 셀 추출 함수(폴백 셀 제외) 단위테스트.
- Playwright: 복기 1라운드 플레이 → 채점 표시 → 점수 누적 → 카톡 공유 링크 양뷰.
- preship + 박탈감/컴플 카피 점검.

## 페이징
1. **복기 MVP**(재미 가설 검증) → 2. 라이브 예측 + 촉 랭킹 → 3. (장기) 촉 좋은 사람 팔로우/예측 구독 = 부동산 인플루언서化(사업성 2차).

# 구현 플랜 (MVP) — 2026-05-31

> 데이터 검증 완료: `trendIndex.series`에 **시군구|tier 106셀 + 14개월** 존재, peer(`수도권|tier`)와
> 실제 상이 → 게임 성립·복기 풀 충분. 전부 번들·DB0. MVP = 복기(instant) + 라이브(pending) 둘 다
> (라이브가 "안목 게임"의 무게 — 복기만이면 trivia로 가벼워짐).

## 파일
- `src/lib/game/predict.ts` (순수 로직):
  - `playableCells()` — `trendIndex.series`에서 **수도권|* 제외 + 자기 series 보유 + 개월수 충분**인 (sgg,tier) 셀 목록.
  - `peerKeyOf(tier)` = `수도권|{tier}`.
  - `scoreRound({cellKey, fromMonth, toMonth, pick})` — `cellΔ=idx[to]/idx[from]-1`, `peerΔ` 동일. `outperform=cellΔ>peerΔ`, `correct=(pick==="UP")===outperform`. 반환 `{resolvable, correct, cellPct, peerPct}`. 엣지: 월 데이터 없음/동률/peer 없음 → resolvable=false.
  - `backtestRound(seed)` — 결정적(seed=날짜+n) 셀+과거 (from,to) 윈도우 출제(복기).
  - `liveRound(seed)` — 셀 + (latestMonth → +horizon) 미래 예측 출제.
- `tests/predict.test.ts` (**TDD 먼저**): scoreRound 4케이스(아웃퍼폼/언더/동률/결측), playableCells(수도권·결측 제외), backtest 결정성.
- `src/components/PlayExperience.tsx` + `src/app/play/page.tsx` (client): 라운드 카드(셀+기간) → UP/DOWN → 복기 즉시 채점 / 라이브 "발표 대기" → 촉 점수·연승·"촉 N단". 카톡 도발 공유 + 면책. 통장 연결 1줄(localStorage 예산 있으면).
- 상태: localStorage(점수·연승·pending 라이브 예측). **No-PII.**
- 라이브 resolve: 마운트 시 `pending` 중 `toMonth ≤ latestMonth` 인 것 `scoreRound`로 채점.
- 진입: 랜딩/결과에서 `/play` 링크.

## TDD 순서
1. `predict.ts` (scoreRound·playableCells·backtest) + 테스트 → 로직 확정.
2. 복기 모드 UI(즉시 채점) — *재미 가설 검증 핵심*.
3. 라이브 pending + resolve.
4. 점수·연승·촉단 localStorage.
5. 카톡 도발 공유 + 면책 + 통장 1줄.
6. Playwright E2E(복기 1라운드→채점→점수→공유) + preship.

## 가드
- 랭킹 축 = **촉 정확도만**(돈 랭킹 금지). 오답=선망("촉 키우자"), 시기 금지.
- 면책: "시세 감각 게임 · 예측·투자권유 아님 · 국토부 실거래 기반 지수".

## MVP 컷
복기+라이브·점수/연승/촉단·공유. **타인 랭킹·구독·통장 정밀연결 = 2차.**

## 검증
predict 단위테스트 · Playwright(복기 플레이→채점→점수→공유 양뷰) · preship · 면책/박탈감 카피 점검.
