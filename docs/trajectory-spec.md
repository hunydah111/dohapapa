## 무엇을 보여주나
입력(저축여력·현재 자기자본·상승률 가정)을 토대로 **시간이 갈수록 진입 가능해지는 동네 사다리**:

```
지금        금천구 84㎡ 진입권 (현재 구매력 6.5억)
1년 6개월 뒤  광명시 84㎡ 진입권  (+0.8억 저축, 추정)
3년 뒤       안양 동안구(평촌) 84㎡ 진입권
5년 2개월 뒤  성남 분당구 84㎡ 진입권
```
- 감정: "지금 못 가는 동네가 영영 못 가는 게 아니다" = 희망·재방문·공유 동력.
- 컴플라이언스: 전부 **"추정 시나리오"** 라벨 + "미래가치 예측·투자권유 아님" 선. 단정 금지.

## 이미 가진 재료 (런타임 DB 0 — 전부 스냅샷/번들)
- `src/data/regionPrices.json` — **72 시군구 × 6 평형 × 3티어(stable P40·balanced P65·challenge P90) + 대표단지**. `asOf` 2026-04.
- `src/lib/plan/index.ts` — `computePlan`·`planMonthsFor`(목표가까지 개월)·`formatDday`·`planGuidance`.
- `src/lib/plan/priceScenarios.ts` — `regionScenarios(sgg)`·`defaultUpPct(sgg)`·`DEFAULT_APPRECIATION{down,flat,up}` (서울 +5%/경기 +3% KB 10년 CAGR 근거).
- `src/lib/budget.ts` — 구매력 추정(현 시점).
→ **새로 짤 건 "예산(T) → 진입 가능 시군구 매핑 + 사다리 정렬" 로직과 뷰뿐.** 무거운 데이터는 다 구워져 있음.

## 핵심 알고리즘
1. **현재 구매력** `B0` = 기존 budget 추정.
2. **미래 구매력** `B(T)` = `B0 + (월저축 × 12 × T)` (대출한도는 소득 불변 가정 시 일정 — 자기자본만 증가; 보수적). T = 0.5년 간격, 0~7년.
3. **각 시군구의 목표 진입가** `P_region(T)` = `regionPrices[sgg][평형].tiers[ENTRY].krw × (1 + up_sgg)^T`.
   - 평형 = **사용자 preferredAreaRanges 1순위** (사다리가 희망 평형 유지).
   - 상승률 = `regionScenarios(sgg)` 시나리오(기본 flat? 또는 사용자 선택 up/flat/down — **결정 필요 D3**).
4. **진입 시점** = `B(T) ≥ P_region(T)` 되는 최초 T. (양쪽 다 시간에 따라 움직임 — 동네가 더 빨리 오르면 멀어짐 = 정직.)
5. **사다리 구성** = 진입 시점이 가까운 순으로 N개 rung. 단 **정렬·필터 기준 D2 결정 필요**.

## 반드시 사용자가 결정할 것 (스펙 확정 전)

| # | 결정 | 옵션 | 내 추천 |
|---|------|------|---------|
| **D1** | "진입 가능" 기준 티어 | stable(P40·발들임) / balanced(P65·중간) | **stable P40** — "사다리 첫 칸" 의미. 카피로 "안정형 가격대 진입" 명시 |
| **D2** | 사다리에 올릴 동네 정렬·필터 | (a)가격 오름차순 전체 (b)통근 가능권만 (c)현재 거주/관심권 인접 | **(b) 통근 ≤ 사용자 한도×1.5 인 시군구만** — 안 그러면 "가평이 다음 칸"처럼 무의미. workplace 없으면 가격순 |
| **D3** | 미래 동네가격 상승률 | flat(0%·보수) / 사용자가 /plan에서 고른 시나리오 / 지역별 기본 | **flat 기본 + 토글로 up 시나리오** — 상승 가정은 "사다리가 멀어지는" 정직한 부작용을 보여주되 디폴트는 보수 |
| **D4** | 대출한도 미래 변화 | 소득 고정(자기자본만↑) / 소득도 성장 가정 | **소득 고정** — 성장 가정은 과약속. 보수적이 신뢰 |
| **D5** | 진입 위치 | /plan 새 섹션 / 결과 페이지 새 탭 / 독립 라우트 | **/plan 새 섹션** — 이미 시간축·저축모델·D-day 다 있음. 재료 재활용 |
| **D6** | rung 개수·범위 | 3 / 5 / 동적 | **현재 동네 + 위로 3칸(총 4)** — 너무 많으면 사다리 압도 |
| **D7** | "못 올라가는" 케이스 | 저축<상승 시 | **"지금 동네에서 평형 키우기" 또는 "현금흐름 먼저" 폴백** — 빈 화면 금지([[feedback-no-empty-results]]) |

- 공유 카드: 비지 + "나 5년 뒤 분당 입성 예정 🦫" (바이럴, 등급 카드와 동일 파이프).
