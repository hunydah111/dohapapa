# `<개선가능>` — 신뢰도/품질 개선 백로그 (비용·데이터·외부의존으로 미룬 것들)

> **트리거 규약**: 사용자가 채팅에 `<개선가능>` 이라고 치면 → Claude는 이 문서를 읽고
> 현황을 요약해 보여준다(+ 새로 미룬 항목이 생기면 여기 추가). 프로젝트 시작~2026-05-29 전수조사.
>
> 분류: **비용**=외부 API 호출비·운영비, **데이터**=데이터 획득/적재 필요, **외부의존**=키/쿼터/제3자,
> **효ort**=구현 공수, **모델**=정밀화 여지. 임팩트는 *신뢰도(추정 정확도)* 중심.
>
> 핵심 원칙: 솔로 운영자 비용 민감([[feedback-api-cost]]) + price-first 정직([[feedback-price-first-scoring]])
> + 빈 화면 금지([[feedback-no-empty-results]]). "고치는 것보다 안 보여주는 게 나을 때가 있다."

## 갱신 규칙
- 새로 "비용/데이터/외부의존으로 미룬 신뢰도 개선"이 생기면 **즉시 이 표에 한 줄 추가**(ID 부여).
- 구현 완료 시 해당 행에 ~~취소선~~ + 커밋 해시.
- `<개선가능>` 입력 시: 미완 항목을 임팩트·분류별로 요약 + "지금 칠 만한 것" 1~2개 추천.
