# 모델 가정 카드 (model assumptions)

**목적**: 코드 안 "단일 줄로 단순화된 가정"은 정책 변화에 가장 취약하다. 표(`policy-watch.md`)는 *값*을 추적하지만 가정 자체는 표 밖에 있어 누락이 통과한다. 이 파일은 6개월에 한 번씩 **가정 자체를 의심**하는 루틴의 단일 진실이다.

## 점검 룰

- **6개월마다** 각 가정 카드를 펼쳐 *해당 가정이 여전히 유효한 단순화인가?*를 묻는다.
- 가정이 깨지면 → 코드에 분기 도입 + `policy-watch.md` 표에 새 차원 추가.
- 가정 등록 시점·마지막 점검일·다음 점검 시한을 함께 기록한다.

## 부록: 사고 이력 (가정 누락 사례)

### 2026-05-26: 토허제·인천·규제지역 차등 누락

- **상황**: 사용자가 "동탄 같이 토허제 아닌 곳들 구분되어 있나?"·"인천 빠뜨렸나?" 두 번 지적해 잡힘.
- **원인**: `budget.ts:5` "서울 전역 규제 가정" 한 줄짜리 단순화가 표(policy-watch.md)의 점검 차원 밖에 있었음. 표는 *값*만 추적해 ✅로 통과시킴.
- **재발 방지**: ①policy-watch.md 에 "점검 차원" 절 추가 — 값 외 지역 차등·허가 절차·시점 의존도 능동적 점검. ②이 model-assumptions.md 신설 — 단일 줄 가정 자체를 6개월마다 의심.
- **솔로 운영 약점**: 외부 리뷰어 0 = 사용자 한 마디가 유일한 회로 차단기. 점검 시 표 ✅에 만족하지 말고 "이 모델이 *틀릴 수 있는 차원*"을 일부러 던지는 질문(예: "정책이 지역별로 차등 적용된 적 있는가?")을 셀프 체크리스트로.
