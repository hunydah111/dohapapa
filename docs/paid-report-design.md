# 유료 리포트 설계 — "심층 단지 리포트"

> 시장 리서치 결과 TOP 1 수익 모델. 솔로 창업자가 3개월 안에 실험 가능,
> 법적 트리거 0, 결제율 자체가 P/M Fit 신호 — 수요 검증 도구 겸용.

## 1. 가설

- 무료 결과(3티어 + 10추가) 본 사용자가 **한 단지를 더 깊이 알고 싶을** 때 결제한다.
- 검증 지표: 결제전환 1% 이상 (베타 3개월 내), NPS 30+.
- 미달 시: 가설 폐기 또는 가격·콘텐츠 재설계.

## 2. 가격

- **단일 단지**: 4,900원 (베타 테스트) → 9,900원 (정상)
- **3단지 묶음 (티어 전부)**: 13,900원 (3단지 × 9,900원 대비 ~53% 할인)
- A/B 테스트: 베타 100명 대상 4,900 vs 9,900 — 단가 × 전환률 비교

## 4. 결제 흐름

1. 무료 결과 카드에 **"이 단지 심층 리포트 9,900원"** CTA 추가
2. 클릭 → 토스페이먼츠 결제 위젯 (사업자 미등록 상태에선 개인 정산 한도 내 테스트)
3. 결제 완료 → 서버에서 PDF 생성 (puppeteer 또는 react-pdf) → 즉시 다운로드 + 이메일 발송
4. 결제 ID 로 30일간 같은 PDF 재다운로드 가능 (private URL)

## 5. 기술 스택

| 영역 | 선택 | 근거 |
|---|---|---|
| PDF 생성 | **puppeteer headless** (HTML→PDF) | 디자인 통제 쉬움, 기존 CandidateCard JSX 재사용 가능. 무거우면 react-pdf 대안. |
| 결제 | **토스페이먼츠 위젯** | 한국 결제 표준, 개인 정산도 가능 (사업자 등록 전엔 누적 한도 주의). 위젯이라 PCI 부담 없음. |
| 보관 | Prisma `Order` 테이블 — `paymentId`, `email`, `complexId`, `profileSlug`, `createdAt`, `expiresAt` | 영수증·재다운로드용. 이메일은 영수증 발송에만 사용 (마케팅 X). |
| 발송 | **Resend** 또는 **AWS SES** | 솔로면 Resend 무료 한도 충분. |

## 6. 컴플라이언스 — 절대 금지 표현

법무 리서치 결과 반영. 다음 표현은 **자본시장법·표시광고법·중개사법** 리스크:

| 금지 | 허용 (대체) |
|---|---|

| "수익률 X%", "향후 가치 전망" | "최근 6개월 실거래 중위가", "거래 추이" |

## 8. 단위 매출 계산 (정성)

- 결제 9,900원 × 결제전환 1% × 월 활성 1만 명 = **월 매출 99만 원**
- 부동산플래닛 누적 1.6만 결제 = 비교 벤치마크 (시장 시그널: 있음)
- 솔로 창업자 운영비 (Vercel + 도메인 + Resend + 토스 수수료 ~3%) 월 ~10만 원
- 손익분기: 월 결제 10건 (10만 원) — 진입 장벽 낮음

## 9. 첫 결제 100건 안에 알아야 할 것

1. **결제전환률** — 1% 미만이면 가설 폐기 / 가격 인하 / 콘텐츠 보강 결정.
2. **NPS** — 30+ 면 가치 검증, 30 미만이면 콘텐츠 부족.
3. **재구매율** — 같은 사용자가 다른 단지 리포트도 사는가? 사면 → 구독제(모델 2) 신호.
4. **공유율** — 리포트 받은 사용자가 친구 부부에게 공유하는가? 공유 1건당 신규 0.3+ 면 바이럴.
5. **가장 자주 본 섹션** — Page 분석 (예: 정책대출 페이지가 가장 인기면 그 단독 상품화 검토).

## 10. 안 할 것

- 부동산 시세 예측 (자본시장법 리스크)
- 매물 직접 연결 (중개법 리스크)
- 대출 상품 비교·신청 페이지 연결 (대출모집업 리스크)
- 베스트·추천 등 단정형 라벨링
- 마케팅 목적 사용자 이메일 수집·발송 (영수증·재다운 외)
