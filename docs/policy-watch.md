# 정책·세제 변경 감지 체크리스트 (policy-watch)

이 문서는 **주간 스케줄 에이전트(정책 변경 감지 루틴)의 점검 명세**다. 사람도 이대로 수동 점검 가능.

## 루틴이 매주 할 일
아래 각 항목을 **공식 출처와 대조**한 뒤:
- **값이 바뀌었으면** → 해당 코드 상수 + `src/lib/policyLoan.ts`의 `POLICY_META.effectiveLabel` 갱신 **PR 생성**(이 표의 출처 링크를 PR 본문에 첨부). **자동 머지 금지** — 사람이 PR 리뷰 후 머지 = 승인.
- **값이 그대로면** → `src/lib/policyLoan.ts`의 `POLICY_META.lastVerified`를 점검일로 갱신(커밋). → 결과화면/첫화면의 "최신 점검됨" 배지가 정직하게 유지됨.
- 한도·세율은 **시점 의존**이라 단정 금지 — 불확실하면 PR 대신 "확인 필요" 보고만.

기준 시점: **POLICY_META.lastVerified = 2026-05-26** · 반영: 2025.6.28 개정(디딤돌 한도) + 2025.10.16 스트레스 DSR 3단계 수도권 +3.0%p

> ⚠️ 주택가격 요건은 현재 **코드 계산에 미반영**(예산 추정 시점엔 매수 희망가 미상) — `policyLoan.ts`의 reason 문자열에만 안내. 그래도 정확해야 하므로 함께 점검.

## 처리 이력 / 미결
1. ✅ **중개보수 요율**(`calcBrokerRate`) — 2026-05-25 공식 구간(2~9억0.4%/9~12억0.5%/12~15억0.6%/15억↑0.7%)으로 정정 + 잠금 테스트 추가.
2. ✅ **디딤돌 신혼 주택가 reason** — 2026-05-25 5억→6억 정정.
3. ✅ **스트레스 DSR 수도권 +3.0%p 반영** — 2026-05-26: `STRESS_RATE` 5.5→7.0(=4.0+3.0)으로 상향. 2025.10.16 스트레스 DSR 3단계 시행분(수도권·규제지역 주담대). 앱이 수도권 전용이라 일괄 적용. DSR 대출 추정이 ~15% 줄어드는 게 정상.
4. △ **미결** — LTV 가격대별 캡(15~25억 4억/25억↑ 2억) 정밀 적용엔 `estimateBudget`에 타깃가 패스 리팩터링 필요. 주 타깃(생애최초 ≤12억)은 현 flat 6억으로 정확.
