# 허위매물 의심도 점수 체계

## 개요

의심도 점수는 0에서 100 사이의 정수입니다. 8개 신호가 각각 독립적으로 점수를 산출하고, 이를 합산한 뒤 `[0, 100]` 범위로 clamp합니다. 점수가 높을수록 허위매물 가능성이 높음을 의미합니다.

공유 타입과 가중치는 `src/types/listing.ts`에 정의되어 있으며, 모든 스코어러 모듈은 이 파일에서 import해야 합니다.

## 의심도 밴드

| 밴드 | 범위 | 표시 색상 | 의미 |
|------|------|-----------|------|
| green | 0 – 39 | 초록 | 이상 신호 없거나 미미함 |
| yellow | 40 – 69 | 노랑 | 주의가 필요한 신호 존재 |
| red | 70 – 100 | 빨강 | 허위매물 가능성 높음 |

```typescript
// src/types/listing.ts
export function bandFor(total: number): "green" | "yellow" | "red" {
  if (total >= 70) return "red";
  if (total >= 40) return "yellow";
  return "green";
}
```

## 신호별 상세 설명

### price — 가격 이상치 (최대 30점)

동일 단지, 유사 평형(±3㎡), 최근 3개월 실거래 중위가 대비 호가의 z-score를 계산합니다. 비교 거래가 3건 미만이면 데이터 부족으로 0점 처리합니다.

| z-score | 점수 | 사유 예시 |
|---------|------|-----------|
| >= 0 (호가 >= 중위) | 0 | — |
| -1.0 <= z < 0 | 0 | 중위 대비 -X% (정상 범위) |
| -2.0 < z < -1.0 | 1–29 (선형 보간) | 중위 대비 -X% (이상치 의심) |
| <= -2.0 | 30 | 중위 대비 -X% (강한 이상치) |

z-score 계산: `(호가 - 중위가) / 표준편차`

구현: `src/lib/score/price.ts` / 비교 집합 생성: `src/lib/comparables.ts`

---

### brokerConcentration — 중개사 집중도 (최대 15점) — placeholder

동일 단지에서 특정 중개사가 지나치게 많은 매물을 등록하는 패턴을 탐지합니다. 허위매물의 경우 한 명의 중개사가 다수의 미끼 매물을 올리는 경향이 있습니다.

현재 MVP에서는 중개사 데이터 누적이 진행 중이므로 항상 0점을 반환합니다.

---

### stale — 시장 체류일 (최대 10점)

매물 등록일(`postedAt`)부터 현재까지의 경과일을 측정합니다. 장기 체류 매물은 실제로 거래 의사가 없거나 미끼 목적으로 게시된 경우가 많습니다.

| 경과일 | 점수 | 사유 |
|--------|------|------|
| < 30일 | 0 | — |
| 30 – 59일 | 5 | 등록 후 N일 경과 (장기 체류) |
| >= 60일 | 10 | 등록 후 N일 경과 (이례적 장기 체류) |

`postedAt`이 제공되지 않으면 0점 처리합니다.

---

### refresh — 수정일자 갱신 패턴 (최대 15점)

실질적인 내용 변경 없이 타임스탬프만 갱신하는 행위("새로고침")는 포털 상단 노출을 유지하려는 active bait 전략의 특징입니다. 최근 7일 이내의 무변경 갱신(`modified === false`) 횟수를 기준으로 점수를 부여합니다.

| 7일 내 무변경 갱신 수 | 점수 | 사유 |
|----------------------|------|------|
| 0 – 1회 | 0 | — |
| 2회 | 8 | 7일 내 무변경 갱신 2회 (상단 노출 의심) |
| >= 3회 | 15 | 7일 내 무변경 갱신 N회 (상단 노출 active bait 의심) |

`refreshHistory`가 제공되지 않거나 2건 미만이면 0점 처리합니다.

---

### photoReuse — 사진 재사용 (최대 10점) — placeholder

동일한 사진이 여러 매물에 재사용되는 패턴을 탐지합니다. 이미지 핑거프린팅(지각 해시 등)을 통해 구현 예정입니다.

현재 MVP에서는 사진 분석 데이터 누적 중이므로 항상 0점을 반환합니다.

---

### info — 정보 부실 (최대 5점)

필수 정보가 누락된 매물은 실제 거래 의사가 없거나 급조된 미끼 매물일 가능성이 있습니다. 층, 향, 상세설명(20자 이상), 사진 유무를 검사합니다.

| 누락 항목 수 | 점수 |
|-------------|------|
| 0 | 0 |
| 1 | 2 |
| 2 | 4 |
| >= 3 | 5 |

---

### keywords — 미끼 키워드 (최대 5점)

매물 설명에 허위매물에서 자주 사용되는 키워드가 포함되어 있는지 검사합니다.

검사 키워드: 급매, 급처분, 즉시입주, VIP, 확실, 로얄, 방금, 초특가, 단독, 특A, 이번주만, 이번 주만, 선착순

| 매칭 키워드 수 | 점수 |
|--------------|------|
| 0 | 0 |
| 1 | 2 |
| 2 | 4 |
| >= 3 | 5 |

---

### brokerHistory — 중개사 이력 (최대 10점) — placeholder

과거 허위매물 신고 이력이 있는 중개사의 매물은 의심도를 높입니다. KISO 부동산매물클린관리센터 등의 데이터 연동이 필요합니다.

현재 MVP에서는 중개사 이력 데이터 누적 중이므로 항상 0점을 반환합니다.

---

## 점수 계산 예시

가격은 중위 대비 -2.5σ (30점), 무변경 갱신 3회 (15점), 등록 후 45일 (5점), 층/향 누락 (4점), 미끼 키워드 1개 (2점)인 경우:

```
30 + 0 + 5 + 15 + 0 + 4 + 2 + 0 = 56점 → yellow 밴드
```
