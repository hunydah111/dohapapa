# 단지 점수화 및 후보 선별 모델

## 개요

`recommendComplexes()`는 하드 필터를 통과한 단지에 대해 4개 신호를 점수화하고, 총점 순으로 정렬한 뒤 안정형·균형형·도전형 3개 후보를 반환합니다. "추천"이라는 표현은 사용하지 않으며, 결과는 "조건에 맞는 단지" 형태의 정보 제공으로 제시합니다.

## 1. 하드 필터

점수 계산 전에 다음 조건을 통과하지 못한 단지는 후보 풀에서 제외합니다.

| 필터 | 기준 |
|------|------|
| 예산 초과 | 단지 대표 평형 실거래 중위가 > `netPurchasePowerKrw` |
| 통근 초과 (A) | 단지 → workplaceA 통근 시간 > `maxCommuteMinutesA` (기본 50분) |
| 통근 초과 (B) | workplaceB 가 입력된 경우, 단지 → workplaceB 통근 시간 > `maxCommuteMinutesB` (기본 50분) |

두 조건 모두 OR 이 아닌 AND 로 적용합니다. 즉, 한쪽이라도 허용 시간을 초과하면 제외합니다.

## 2. 4개 신호와 기본 가중치

기본 가중치는 `src/types/recommendation.ts`의 `CANDIDATE_SIGNAL_WEIGHTS`에 정의되어 있습니다.

| 신호 키 | 한국어 레이블 | 기본 가중치 |
|---------|--------------|------------|
| `commute` | 통근 | 40 |
| `budgetFit` | 예산 적합도 | 30 |
| `school` | 학군·자녀 | 20 |
| `buildingAge` | 단지 연식 | 10 |
| **합계** | | **100** |

각 신호는 0–100 사이의 점수를 산출하며, 가중 평균으로 총점을 계산합니다.

### commute — 통근 (기본 40점)

양측 통근 시간의 가중 평균(workplaceB 미입력 시 A 단독)을 기준으로 점수를 산출합니다. 허용 시간 대비 비율로 선형 환산하며, 허용 시간 이내일수록 높은 점수를 받습니다.

### budgetFit — 예산 적합도 (기본 30점)

단지 중위가와 `netPurchasePowerKrw`의 차이를 기준으로 점수를 산출합니다. 예산 상한에 가까울수록(단, 초과하지 않는 범위) 높은 점수를 받습니다. 여유가 클수록 안정성은 높지만 budgetFit 점수는 낮아집니다.

### school — 학군·자녀 (기본 20점)

`childrenAges`가 빈 배열이면 0점 고정입니다. 자녀가 있는 경우 `nearestElemSchoolM`(최단 초등학교 도보 거리)를 기준으로 점수를 산출합니다. 학교알리미 데이터는 향후 통합 예정이며, MVP에서는 시드 추정값을 사용합니다.

### buildingAge — 단지 연식 (기본 10점)

`buildYear`가 최근일수록 높은 점수를 받습니다. 준공 후 5년 이내 최고점, 20년 초과 시 최저점으로 선형 감소합니다.

## 3. primaryConcern에 따른 가중치 재조정

사용자가 선택한 `primaryConcern`에 따라 해당 신호의 가중치를 높이고 나머지를 비례 축소합니다. 합계는 항상 100을 유지합니다.

| primaryConcern | 조정 신호 | 효과 |
|----------------|-----------|------|
| `commute` | commute | 통근 가중치 상향 |
| `school` | school | 학군·자녀 가중치 상향 |
| `budget` | budgetFit | 예산 적합도 가중치 상향 |
| `loan` | budgetFit | 예산 적합도 가중치 상향 (대출 한도 걱정은 예산 여유와 동일 방향) |

## 4. 3-tier 후보 선별

하드 필터 통과 후 총점 내림차순으로 정렬하고 다음과 같이 tier를 부여합니다.

| tier | 선택 기준 | 의미 |
|------|-----------|------|
| 안정형 | 총점 1위 | 가장 균형적으로 조건에 부합하는 단지 |
| 균형형 | 총점 2위 | 중간 절충점 |
| 도전형 | 총점 3위 | 예산·통근 중 한쪽이 타이트하지만 다른 신호가 우수한 단지 |

후보가 3개 미만이면 가능한 수만큼 반환합니다.

## 5. 예산 추정 공식

예산 추정은 `src/lib/budget.ts`에서 수행하며, 결과 타입의 `isEstimate: true` 필드로 추정값임을 타입 레벨에서 강제합니다.

```
월 상환 가능액 = (연 가구소득 / 12) × DSR_LIMIT(0.40) - existingLoanMonthlyKrw
대출 추정액   = 월 상환 가능액 / (스트레스 DSR 적용 월 이율)   ← LTV 상한과 min 취급
grossBudget   = seedMoneyKrw + 대출 추정액
acquisitionCosts = 취득세 + 중개수수료 + 부대비용   (src/lib/acquisitionCost.ts)
netPurchasePower = grossBudget - acquisitionCosts
```

- 스트레스 DSR: 기준 금리에 +3%p 가산한 가상 금리를 적용해 보수적으로 계산합니다.
- LTV: 생애최초(`hasOwnedHomeBefore = false`) 여부에 따라 상한이 달라집니다.
- 취득세: `hasOwnedHomeBefore` 및 매매가 구간에 따라 감면 여부를 판정합니다.
- 결과 화면과 카드에는 항상 "(추정)" 레이블이 표시됩니다. 실제 대출 한도는 금융기관 심사 결과에 따릅니다.
